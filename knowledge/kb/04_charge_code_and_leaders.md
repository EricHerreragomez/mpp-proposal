# Charge Code, Cost Center & Leaders

## Charge Code
- Mandatory; source of truth. Cost Center Department and Cell are derived automatically.
- Must be valid/active, belong to the correct org/cell, align with pathway.
- Not charged until cloud resources or Platform McKinsey services are consumed (automated billing).
- No code? Check which code other products in your department use, use your team's cost center, or confirm with Department/Finance lead.

## Update steps
1. My Product Portal → open product → Edit
2. Update Charge Code
3. Verify Cost Center Department and Cell populated correctly
4. Review all tabs → Submit
Only PM/TL. Common failures: inactive code, code not in your org, Finance mapping issue, misaligned with pathway → "Tell us about wrong data!".

## Accountable Leader
Determined automatically (see Decision Engine §6). Cannot be manually changed. Approval routing / mapping questions → tech_risk@mckinsey.com.

## Group Engineering Leader
Not editable. Auto-imported from Cost Center Department Code (from Charge Code). After Charge Code change, allow ~24h for import. If Cost Center/Department are correct but leader is still wrong → tech_risk@mckinsey.com.
