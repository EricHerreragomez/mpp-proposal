# Ownership, Roles & Access

## Who can edit
- Product Manager and Technical Lead have edit rights (PM is primarily responsible and confirms data accuracy).
- Department/Solution Leader also has editor access per KB KO98628.
- Access in MPP is granted by roles on the product. To give someone access, PM/TL adds them to an appropriate role → Submit.

## Updating PM / TL / Sponsor / Name / other fields
1. My Product Portal → open product
2. Click Edit
3. Update the field (PM, TL, Sponsor, Name, Practice Tech Enablement Leader, etc.)
4. Review all tabs → Submit
- Products must keep valid ownership (PM, TL, Sponsor) — when removing an owner, assign a replacement.
- If the current PM is unavailable, the TL can update (and vice versa); tag the other for transparency.
- If the requester isn't PM/TL → coordinate with current PM/TL.
- PM and TL both inactive / left the Firm → "Tell us about wrong data!". After MPP Team assigns a new PM, the new PM should review all tabs: TL vacancy, Charge Code, Sponsor, compliance indicators, Self-Assessment Documents, IRP (reviewed within last year), PSR.

## External workers
Cannot be PM, TL, Sponsor, or Department Leader → cannot get edit rights.
Can be listed in UX and Security roles.
They can prepare updates; an internal PM/TL submits them.

## IRP (Incident Response Plan)
- Editable only by PM and TL; read-only for everyone else after submission.
- Should be reviewed within the last year and refreshed on scope changes.
- IRP link / Qualtrics error: not an MPP issue. Check: you're listed as PM/TL; IRP indicator visible (product → Lifecycle). Try incognito/re-login. Then contact the IRP/Qualtrics support team. Incident response content → SOC@mckinsey.com.
